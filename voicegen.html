Голос

🔎 Библиотека голосов — только для платного плана
На бесплатном плане голос из библиотеки можно послушать и добавить к себе, но озвучить через API нельзя — ElevenLabs отвечает 402. Для записи фраз годятся только стандартные голоса.
Без слова в поиске показываются популярные голоса выбранного языка. ▶ — послушать. Голос добавляется сразу во все аккаунты, иначе после перехода на другой аккаунт его там не окажется.
Код для модели (для своих вариантов)
Модель видит английские подсказки в квадратных скобках перед фразой и сама их не произносит. Можно дописать свою, например [proudly].
